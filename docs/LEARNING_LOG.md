## 2026-02-15 — День 1: Структура проекта и окружение

### ✅ Сделано
- Создан репозиторий на GitHub: `aviation-assistant-bot`
- Настроено виртуальное окружение на **Python 3.14.0** (официальный релиз)
- Создана правильная структура пакетов:

  - Подпакеты: `bot`, `nlp`, `api_clients`, `core`, `models`

- Установлены минимальные зависимости без ошибок компиляции:
  - `aiogram==3.12.0`
  - `python-dotenv==1.0.1`
  - `aiohttp==3.10.0`

### ⚠️ Проблемы и решения
| Проблема | Решение | Вывод |
|----------|---------|-------|
| `python --version` показывал 3.13.4 вместо 3.14.0 | Использовал `py -3.14 -m venv .venv` для явного указания версии | Несколько версий Python могут сосуществовать; важно явно указывать нужную |
| Ошибка компиляции `pydantic-core` при установке зависимостей | Отложил установку `pydantic` до этапа конфигурации; начал с минимального набора | Не все библиотеки сразу имеют wheels для новой версии Python — стартуйте с минимума |
| Команда `rmdir /s /q` не работала в PowerShell | Использовал `rmdir -Recurse -Force .venv` (синтаксис PowerShell) | CMD и PowerShell имеют разный синтаксис — важно знать среду |

### 💡 Ключевые открытия
- Виртуальное окружение изолирует зависимости — критически важно при работе с разными проектами
- `.gitignore` — первый барьер против утечки токенов. Проверяю ДО каждого коммита: `git status`
- Python 3.14.0 требует обновлённого `pip` для корректной установки зависимостей: `python -m pip install --upgrade pip`

### ⚠️ Проблемы и решения
| Проблема | Решение | Вывод |
|----------|---------|-------|
| Сначала пытался использовать `/` в юзернейме бота | Изучил правила Telegram: только латиница, цифры, `_` | Внимательно читать требования платформы |
| Бот не отвечал на фото/видео | Добавил проверку `if not message.text` | Всегда валидировать тип входящих данных |

### 💡 Ключевые открытия
- aiogram 3.x использует роутеры (`Router`) вместо старого `Dispatcher` — более гибкая архитектура
- Логирование через `logging` критически важно для отладки асинхронных ботов
- Локальный запуск бота не требует деплоя — поллинг работает напрямую с Telegram API
